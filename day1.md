# Linux Commands Notes

ls
→ Lists files and directories in the current folder

cd directory_name
→ Changes current directory

pwd
→ Shows present working directory (current location)

ncal
→ Displays calendar in a vertical format

cat file.txt
→ Displays contents of a file

cat -n file.txt
→ Displays file contents with line numbers

gedit file.txt
→ Opens file in Gedit graphical text editor

mkdir folder_name
→ Creates a new directory/folder

rmdir folder_name
→ Removes an empty directory

rm file.txt
→ Deletes a file

rm -r folder_name
→ Deletes a folder and its contents recursively
